CHAPTER 01

绪论与复杂度

基础 · 低频
本章定位纯概念章，单选 1-2 题。但时间复杂度分析不属于本章——它是贯穿全书的基本功，每一章的算法都要考复杂度。所以这章别只背定义，把「算复杂度」这个技能练熟。
考点清单

1. 基本概念

术语含义
数据信息的载体
数据元素数据的基本单位，通常整体处理（如一个学生记录）
数据项构成数据元素的不可分割的最小单位（如学号、姓名）
数据对象性质相同的数据元素的集合
辨析数据元素是「基本单位」，数据项是「最小单位」。一个数据元素可以由多个数据项组成 —— 这是经典送分题。

2. 逻辑结构与存储结构 必考

逻辑结构（面向问题的，与存储无关） 线性结构：线性表、栈、队列、串 非线性结构：树、图、集合 存储结构（面向计算机的，也叫物理结构） 顺序存储：逻辑相邻 → 物理相邻（数组） 链式存储：用指针表示逻辑关系 索引存储：附加索引表 散列存储：由关键字直接算出地址
关系存储结构是逻辑结构的实现。同一个逻辑结构（如线性表）可以有不同存储结构（顺序表 / 链表），因此操作的效率也不同。

3. 算法与五个特性

  • 有穷性：执行有限步后结束（程序可以不满足，算法必须满足）
  • 确定性：每条指令含义唯一，无二义性
  • 可行性：都能用基本运算实现有限次
  • 输入：零个或多个
  • 输出：一个或多个（必须有）
易错「算法必须有输入」是错的 —— 输入可以是零个，但输出至少一个。另外算法 ≠ 程序：程序可以不满足有穷性（如操作系统一直运行）。

4. 时间复杂度 贯穿全书

只保留最高阶项，去掉系数 T(n) = 3n² + 5n + 100 → O(n²) 常见量级（快 → 慢） O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2ⁿ) < O(n!) 两条规则 加法规则：T = T₁ + T₂，取较大的 乘法规则：嵌套循环，复杂度相乘
背下来 折半查找 O(log n)、快排/归并/堆排 O(n log n)、冒泡/插入/选择 O(n²)、 二叉树遍历 O(n)、图的 BFS/DFS O(n+e)。这几个是选择题的常客。

5. 空间复杂度

  • 只算辅助空间，不算输入本身占的空间
  • O(1)：原地算法（冒泡、插入、选择、堆排）
  • O(n)：归并排序（需要等长辅助数组）
  • O(log n)：快排的递归栈（平均）
  • 递归算法的空间复杂度 = 递归深度

6. 常考的几个数

n 个结点的完全二叉树高度 = ⌊log₂n⌋ + 1 折半查找最多比较次数 = ⌊log₂n⌋ + 1 顺序表插入平均移动 n/2 个元素 顺序表删除平均移动 (n−1)/2 个元素 n 个元素出栈序列的种数 = C(2n,n)/(n+1)

CHAPTER 02

线性表

主力 · 4-6 分
本章定位数据结构的第一块基石。顺序表与链表的对比是必考辨析（随机访问 vs 插入删除效率），链表的各种插入删除操作是代码题的基础。这章的题分值不算最高，但后面每一章都在用它——栈是受限的线性表，队列也是，树的存储也要靠数组或链表。
考点清单

1. 顺序表 必考

用一组连续的存储单元依次存放 逻辑相邻 → 物理相邻 优点：随机访问 O(1)，由下标直接算出地址 缺点：插入删除要移动大量元素 O(n) 长度固定，扩容代价高
插入操作（在第 i 个位置插入） 先把第 i 到第 n 个元素整体后移一位 再写入新元素 平均移动次数 = n / 2 删除操作（删除第 i 个元素） 先把第 i+1 到第 n 个元素整体前移一位 平均移动次数 = (n − 1) / 2
记忆插入是从后往前移动（否则会覆盖数据），删除是从前往后移动。这个方向别记反 —— 下面的操作台可以亲手验证。

2. 单链表 必考

结点 = 数据域 + 指针域 用指针把散落的结点串成逻辑上的线性关系 优点：插入删除只需改指针 O(1)（已知前驱时） 缺点：不能随机访问，查找要 O(n) 指针本身占额外空间
插入（在 p 之后插入 s） s->next = p->next; p->next = s; ★ 顺序不能反！反了就丢掉后面的链 删除（删除 p 的后继 q） q = p->next; p->next = q->next; free(q);
带头结点带头结点的单链表能让「第一个位置」和「其他位置」的操作统一，代码更简洁。考试代码题推荐带头结点。判空条件是 L->next == NULL。

3. 双链表

结点 = prior + data + next 可以双向遍历，删除时能直接找到前驱 插入（在 p 之后插入 s）四步 s->next = p->next; if (p->next) p->next->prior = s; s->prior = p; p->next = s; 删除（删除 p 的后继 q） p->next = q->next; if (q->next) q->next->prior = p; free(q);
对比单链表删除某结点需要知道前驱；双链表只要知道该结点本身就能删除（O(1)）。这是双链表存在的核心理由。

4. 循环链表与静态链表

  • 循环单链表：尾结点的 next 指回头结点。判空：L->next == L
  • 循环双链表：头结点的 prior 指向尾结点
  • 静态链表：用数组模拟指针，每个结点存 data + next（游标）。适合不支持指针的语言
考点循环链表的优点是从任一结点出发都能遍历整个链表。若经常操作表尾，可以只设尾指针而不设头指针，此时访问表头和表尾都是 O(1)。

5. 顺序表 vs 链表 必考辨析

顺序表链表
存储方式连续离散
随机访问O(1)O(n)
插入/删除O(n)（要搬元素）O(1)（改指针）
存储密度= 1（无额外开销）< 1（指针占空间）
容量固定，需扩容动态，按需分配
适用查多改少改多查少
结论存储密度 = 数据本身占的空间 ÷ 结点总空间。顺序表为 1，链表小于 1（单链表通常约 50%，取决于数据域大小）。

6. 常见代码题套路

  • 链表逆置（头插法重建）
  • 找中间结点（快慢指针）
  • 判断有环（快慢指针相遇）
  • 删除倒数第 k 个（双指针间隔 k）
  • 两个有序链表合并
  • 找公共结点（先对齐长度）
通用心法链表题的绝大多数技巧都是双指针（快慢指针 / 前后指针）。遇到「倒数」「中间」「有环」这类词，第一反应就该是双指针。

CHAPTER 03

栈、队列和数组

主力 · 4-6 分
本章定位栈和队列都是「操作受限的线性表」——这是本章最核心的一句话。考点集中在两处：循环队列的队空队满判断（公式必背）和出栈序列的合法性判断（卡特兰数）。另外特殊矩阵的下标计算是稳定的计算题。
考点清单

1. 栈（LIFO）必考

后进先出 · 只在栈顶插入和删除 栈顶 top、栈底 bottom、空栈 top == -1
实现特点
顺序栈数组 + top 指针。共享栈：两个栈从两端向中间长，top0+1 == top1 时满
链栈用单链表，只在头部操作。不存在栈满，且不用设头结点
n 个不同元素依次进栈，可能的出栈序列种数 = C(2n, n) / (n+1) ← 卡特兰数 n=3 时：(6×5×4)/(3×2×1)/4 = 5 种 n=4 时：14 种
合法性判断技巧给定入栈序列，判断某出栈序列是否合法：用栈模拟一遍。另外记住一条：出栈序列中不可能出现「后进先出」被违反的情况——若某元素先出栈，则它之前进栈且未出栈的元素必须按逆序出现在它后面。

2. 队列与顺序队列 基础 · 必懂

队列：先进先出（FIFO）—— 队尾入队、队头出队 front 指向队头元素 rear 指向队尾元素的下一个位置 顺序队列 = 数组 + front / rear 两个指针 入队：data[rear] = x; rear++ 出队：x = data[front]; front++ 队空：front == rear 元素个数：rear − front
顺序队列的致命问题：假溢出 rear 只会一路往右走。当 rear 碰到数组末尾（rear == M）时， 哪怕前面已经出队空出很多格子，也再也进不了队 —— 因为 rear 不能回头。
这叫 假溢出：不是真的没空间，而是空间用不上。
例：M = 5 的数组，入队 4 个再出队 4 个 → front = rear = 4，前面 4 格全空着， 但 rear 已经到头，下一个元素就是进不来。这就是下一张卡片「循环队列」要解决的问题。
口径提醒 有的教材写「front 指向队头元素的前一个位置」，有的写「front 指向队头元素」。 两种约定下的入队 / 出队语句是不一样的，做题先看题干怎么定义。
本页统一用：front 指向队头元素，rear 指向队尾元素的下一个位置。

3. 循环队列 必考公式

队列：先进先出（FIFO） front 指向队头元素，rear 指向队尾元素的下一个位置 顺序队列的「假溢出」：rear 到数组末尾了， 但前面还有空位 —— 用循环队列解决
三种判空判满方案（M 为数组容量） ① 牺牲一个单元（最常考） 队空：front == rear 队满：(rear + 1) % M == front 元素个数：(rear − front + M) % M ② 设 size 计数器 队空：size == 0　队满：size == M ③ 设 tag 标志位 tag = 0 表示最近一次是删除 → 判空 tag = 1 表示最近一次是插入 → 判满 即 front == rear 时看 tag 决定是空还是满
必背方案①的两个公式每年都在考。记法：队满时 rear 再走一步就撞上 front，所以是 (rear+1)%M == front。

4. 双端队列

  • 允许两端都能插入和删除
  • 输入受限：只允许一端插入，两端都能删除
  • 输出受限：两端都能插入，只允许一端删除
  • 判断某个序列能否由双端队列得到：同样用模拟法
考点双端队列的题本质上还是「模拟」——在纸上画一个两端开口的管子，逐个试。

5. 栈的应用 经典

场景怎么用栈
括号匹配遇左括号入栈，遇右括号看栈顶是否匹配
表达式求值中缀转后缀用栈；后缀求值也用栈
递归系统用函数调用栈保存返回地址和局部变量
进制转换除基数取余，余数逆序输出 → 用栈
迷宫求解保存路径，回退时出栈
中缀转后缀规则：遇操作数直接输出；遇运算符，若优先级不高于栈顶则弹出栈顶直到满足条件再入栈；遇左括号入栈，遇右括号弹出到左括号为止。这是手算题的常客。

6. 队列的应用

  • 层次遍历（树的 BFS、图的 BFS）—— 最典型的应用
  • 缓冲区（键盘输入缓冲、打印队列）
  • 页面置换的 FIFO 算法
  • 操作系统的各种调度队列（就绪、阻塞）
与 OS 的接口OS 里的就绪队列、阻塞队列、多级反馈队列，本质就是本章的队列。多级反馈队列是「队列的队列」，属于队列的组合应用。

7. 数组的存储与地址计算 计算题

一维数组：LOC(a[i]) = LOC(a[0]) + i × L 二维数组 a[m][n]（m 行 n 列，每个元素占 L 字节） 【行优先】存完一行再存下一行（C / Java / Pascal） LOC(a[i][j]) = LOC(a[0][0]) + (i × n + j) × L 【列优先】存完一列再存下一列（Fortran / MATLAB） LOC(a[i][j]) = LOC(a[0][0]) + (j × m + i) × L 三维数组（行优先）a[m₁][m₂][m₃] LOC(a[i][j][k]) = LOC(a[0][0][0]) + (i × m₂ × m₃ + j × m₃ + k) × L
怎么记 行优先就是「一行一行数过去」：先整行跳过 i 行（每行 n 个元素），再在本行里数到第 j 个 → 前面一共 i × n + j 个元素。
列优先对称着来：先跳过 j 整列（每列 m 个），再数到第 i 个 → j × m + i。 想不清的时候用 2×3 的小数组在纸上推一遍，比硬记公式稳。
两个最常见的坑 ① 「m 行 n 列」里，行优先乘的是列数 n（因为一行有 n 个元素）， 列优先乘的是行数 m。把两个乘数用反，是这类题最常见的失分点。
② 下标从 1 开始时公式要跟着变：行优先变成 ((i−1) × n + (j−1)) × L。先确认题干的下标起点，再代公式。

8. 特殊矩阵的压缩存储 计算题

对称矩阵（n×n，只存下三角） 元素 a[i][j]（i≥j，下标从 1 开始） 在一维数组中的位置 k = i(i−1)/2 + j − 1 上三角元素（i<j）利用对称性：a[i][j] = a[j][i] 三对角矩阵（带状） k = 2i + j − 3 （i、j 从 1 开始） 稀疏矩阵的两种存法 三元组表：(行, 列, 值) 十字链表：适合非零元个数变化大的场景
最容易错的下标从 0 还是从 1 开始，公式要跟着变。做题先确认题干约定，然后代入小数据验证（比如取 i=j=1 看结果对不对）。

CHAPTER 04

树与二叉树

核心 · 10-13 分
本章定位数据结构分值最高的单章。考点密度极大：二叉树性质计算、遍历序列互推、BST 的删除、AVL 的四种旋转、哈夫曼树的 WPL，每一条都是独立考点。其中 n₀ = n₂ + 1 和 AVL 旋转几乎年年出现。这章的动画建议反复点，尤其是 AVL 旋转——画十张图不如亲手转一次。
考点清单

1. 树的基本性质

结点数 = 所有结点的度数之和 + 1 （= 边数 + 1） 树的度 = 各结点度的最大值 结点的层次从根开始算（根是第 1 层） 树的高度 = 最大层次数
存储方式做法
双亲表示法数组，每项存数据和双亲下标。找双亲 O(1)，找孩子 O(n)
孩子表示法数组 + 每个结点的孩子链表
孩子兄弟表示法左指针指第一个孩子，右指针指下一个兄弟。可把树转成二叉树

2. 二叉树性质 必背

① 第 i 层最多 2^(i−1) 个结点 ② 深度为 k 的二叉树最多 2^k − 1 个结点 ③ n₀ = n₂ + 1 ← 叶子数 = 度为 2 的结点数 + 1 （所有二叉树都成立，年年考） ④ n 个结点的完全二叉树高度 = ⌊log₂n⌋ + 1 ⑤ 完全二叉树中，结点 i 的左孩子是 2i、 右孩子是 2i+1，双亲是 ⌊i/2⌋
n₀ = n₂ + 1 怎么推总度数 = n₁ + 2n₂，总结点数 = n₀ + n₁ + n₂。 又因为「结点数 = 度数 + 1」：n₀+n₁+n₂ = n₁+2n₂+1，解得 n₀ = n₂ + 1。 这个推导过程本身就是一道题，要会写。

3. 四种遍历 核心

先序：根 → 左 → 右 中序：左 → 根 → 右 后序：左 → 右 → 根 层序：逐层从左到右（用队列实现）
由遍历序列唯一确定一棵二叉树 先序 + 中序 → 唯一确定 ✓ 后序 + 中序 → 唯一确定 ✓ 层序 + 中序 → 唯一确定 ✓ 先序 + 后序 → 不能确定 ✗ 原因：先序的第一个是根，后序的最后一个也是根， 两者都无法区分左右子树的分界，必须靠中序。
手算技巧先序的第一个元素是根；在中序里找到这个根，左边就是左子树、右边就是右子树；再递归处理。这个套路练熟后，任何组合题都能解。

4. 线索二叉树

  • 目的：利用 n+1 个空指针域（n 个结点的二叉树有 2n 个指针，用掉 n−1 个，剩 n+1 个空的）
  • 左空指针 → 指向前驱；右空指针 → 指向后继
  • 需要增加 ltag、rtag 标志位区分「线索」和「真实的子树指针」
  • 中序线索二叉树最常用（因为中序序列的前驱后继关系最规整）
考点线索二叉树便于找前驱后继，因此遍历不需要栈（O(1) 空间）。但插入删除结点比较麻烦。

5. 二叉排序树 BST 必考

要么是空树，要么满足： 左子树所有结点 < 根 < 右子树所有结点 （左右子树也分别都是 BST）
删除结点 z 的三种情况 ① z 是叶子 → 直接删 ② z 只有一个孩子 → 用孩子替代 z ③ z 有两个孩子 → 用中序直接前驱（左子树最大值） 或中序直接后继（右子树最小值）替代 z， 然后递归删除那个替身
易错第③种情况不是简单地「把右子树接到左子树上」。正确做法是找替身。另外要记住：中序遍历 BST 得到的是升序序列 —— 这是判断一棵树是不是 BST 的最快方法。

6. 平衡二叉树 AVL 最高频

平衡因子 = 左子树高度 − 右子树高度 要求 |平衡因子| ≤ 1，否则失衡要旋转 四种旋转（看失衡结点与插入位置的关系） LL 型 → 右旋 （插在左子树的左子树） RR 型 → 左旋 （插在右子树的右子树） LR 型 → 先左旋后右旋 （插在左子树的右子树） RL 型 → 先右旋后左旋 （插在右子树的左子树） 记忆口诀：看形状，往哪歪就往反方向转
关键AVL 树的高度是 O(log n)，所以查找、插入、删除都是 O(log n)。旋转只调整局部三个结点，不改变中序遍历序列（即仍然是 BST）。

7. 哈夫曼树

WPL（带权路径长度）= Σ(叶结点权值 × 路径长度) 哈夫曼树的 WPL 最小 构造（贪心） ① 把 n 个权值都当作单结点树，放进集合 ② 每次取最小的两个合并，新结点权值 = 两者之和 ③ 重复直到只剩一棵树
  • 哈夫曼树没有度为 1 的结点（所以 n₀ = n₂ + 1）
  • n 个叶结点的哈夫曼树共有 2n − 1 个结点
  • 哈夫曼编码是前缀编码（任一编码都不是另一个的前缀），保证解码无歧义
  • 左分支记 0、右分支记 1（或反之），编码不唯一

8. 并查集

  • 用双亲表示法的树（数组）实现，每个集合是一棵树
  • Find：顺着双亲指针找根，根的标志是 parent[i] == -1（或 i）
  • Union：把一棵树的根挂到另一棵的根上
  • 优化：按秩（小树挂大树）合并 + 路径压缩
  • 应用：判断无向图连通性、Kruskal 算法
与图的接口Kruskal 最小生成树算法就靠并查集判断加入一条边会不会成环——如果两个端点已经在同一个集合里，加这条边就会成环。见第 5 章。

CHAPTER 05

图

核心 · 7-10 分
本章定位算法最多、手算量最大的一章。考点分三块：存储结构的选择与度/边数计算（送分）、两种遍历（常考序列不唯一的判断）、四个经典算法（Prim / Kruskal / Dijkstra / Floyd）与拓扑排序、关键路径。大题几乎必然要你手写算法执行过程，所以下面每个算法都做了逐步演示。
考点清单

1. 基本概念与几个数 必背

无向完全图边数 = n(n−1)/2 有向完全图边数 = n(n−1) 连通图最少边数 = n−1（就是树） 强连通图最少边数 = n（构成环） 无向图所有顶点度数之和 = 2 × 边数 有向图：所有顶点入度之和 = 出度之和 = 边数 n 个顶点的无向图，若边数 > (n−1)(n−2)/2 则一定连通
握手定理「度数之和 = 2 × 边数」这一条用得最多，几乎每道图的概念题都会用到。

2. 两种存储结构 必考

邻接矩阵邻接表
空间O(n²)O(n + e)
适合稠密图稀疏图
判断两点相邻O(1)O(度)
求某点所有邻接点O(n)O(度)
无向图度该行非零元个数该行结点个数
有向图出/入度行和 / 列和出度看本行；入度要遍历整个表
记忆邻接矩阵的每一行之和是该顶点的出度，每一列之和是入度。无向图的邻接矩阵对称，第 i 行之和就是顶点 i 的度。

3. 十字链表与邻接多重表

  • 十字链表：用于有向图。每个顶点有 firstin / firstout，每条边有 tail/head/hlink/tlink。求入度和出度都方便
  • 邻接多重表：用于无向图。每条边只存一个结点（而不是邻接表里的两个），便于删除边
  • 这两个结构考试一般只考概念和适用场景，不要求手写

4. 两种遍历 必考

BFS 广度优先DFS 深度优先
辅助结构队列栈（或递归）
类比树的层序遍历树的先序遍历
应用无权图单源最短路径连通性判断、拓扑排序
复杂度（邻接表） BFS / DFS 均为 O(n + e) （邻接矩阵则是 O(n²)，因为要找邻接点必须扫一整行）
高频考点邻接矩阵的遍历序列唯一，邻接表的遍历序列不唯一。原因：邻接矩阵的邻接点顺序固定（按顶点编号），而邻接表里结点的次序取决于边的插入顺序。

5. 最小生成树 Prim vs Kruskal 必考

PrimKruskal
思路从顶点出发，每次加一条连接「已选集合」与外界的最短边从边出发，每次选权值最小的边，不成环就加入
复杂度O(n²)O(e log e)
适合稠密图稀疏图
辅助结构lowcost 数组并查集（判环）
结论最小生成树的总权值唯一，但树本身可能不唯一（当存在相同权值的边时）。这一点常考判断题。

6. 最短路径 Dijkstra vs Floyd 大题常客

DijkstraFloyd
求什么单源到其余各点任意两点之间
思路贪心，每次确定一个最近的点动态规划，三层循环
复杂度O(n²)O(n³)
负权不允许允许（不能有负权回路）
Floyd 的核心三行 for (k = 0; k < n; k++) for (i = 0; i < n; i++) for (j = 0; j < n; j++) if (A[i][j] > A[i][k] + A[k][j]) A[i][j] = A[i][k] + A[k][j];

7. 拓扑排序（AOV 网）

AOV 网：顶点表示活动，边表示先后关系 拓扑排序：排出一个线性序列，使所有边都从前指向后 步骤 ① 找一个入度为 0 的顶点，输出 ② 删除该顶点及它的所有出边 ③ 重复①②直到全部输出 若最后还有顶点没输出 → 图中存在环
  • 拓扑序列可能不唯一
  • 用栈或队列都可以实现
  • 应用：课程安排、编译依赖、任务调度

8. 关键路径（AOE 网）

AOE 网：边表示活动（带权=持续时间），顶点表示事件 四个量（ve 最早、vl 最迟） ve(j) = max{ ve(i) + w(i,j) } ← 正向推，取最大 vl(i) = min{ vl(j) − w(i,j) } ← 逆向推，取最小 活动的四个量 e(i) = ve(起点) 活动最早开始 l(i) = vl(终点) − w 活动最迟开始 时间余量 d(i) = l(i) − e(i) d(i) = 0 的活动就是关键活动 关键路径 = 从源点到汇点的最长路径 关键路径的长度 = 完成整个工程的最短时间
易混关键路径是最长路径，但它决定了工程的最短完成时间 —— 因为所有活动都得等最慢的那条链走完。另外关键路径可能不唯一，缩短关键活动不一定能缩短总工期（可能变成新的关键路径）。

CHAPTER 06

查找

主力 · 5-7 分
本章定位考点很集中：折半查找的判定树与比较次数、B 树的插入删除、散列表的 ASL 计算。这三块都有固定套路，属于「练熟就拿满」的题。B 树那一块概念多，重点记阶数与结点数上下限。
考点清单

1. 顺序查找与折半查找 必考

顺序查找 成功 ASL = (n+1)/2 优点：对存储结构无要求、不要求有序 缺点：慢 折半查找（二分查找） 前提：必须是有序表 + 顺序存储 每次比较中间元素，砍掉一半 成功 ASL ≈ log₂(n+1) − 1 最多比较 ⌊log₂n⌋ + 1 次 时间 O(log n)
最容易错的折半查找不能用链表 —— 因为要随机访问中间元素，链表做不到。这是经典送分判断。另外折半查找只适合静态查找表（频繁插入删除时维护有序性代价太高）。
折半查找的判定树 是一棵平衡二叉树 第 k 层最多 2^(k−1) 个结点 n 个元素时树高 = ⌊log₂n⌋ + 1 查找失败时的比较次数 = 树高（或树高 −1）

2. 分块查找

  • 把表分成若干块，块内无序、块间有序（前一块的最大值小于后一块的最小值）
  • 先查索引表确定块（折半或顺序），再在块内顺序查找
  • 平均查找长度 = 索引查找 + 块内查找
  • 当块数 = 每块元素数 = √n 时，ASL 最小 ≈ √n + 1

3. B 树 重难点

m 阶 B 树的要求 每个结点最多有 m 棵子树、m−1 个关键字 根结点至少 2 棵子树（除非它本身就是叶子） 非根内部结点至少 ⌈m/2⌉ 棵子树 所有叶结点都在同一层（绝对平衡） 结点内关键字有序排列
插入：可能引发「分裂」 先按查找路径插到叶子结点 若超出 m−1 个关键字 → 从中间位置分成两半， 中间元素上移到双亲，可能继续向上分裂 若根也分裂 → 树高 +1
删除：分三种情况 ① 在非叶结点 → 用直接前驱（左子树最右）或 直接后继（右子树最左）替代，转为删叶子 ② 删后关键字数 ≥ ⌈m/2⌉−1 → 直接删 ③ 不够借 → 先向兄弟「借」（旋转）， 兄弟也紧张就与兄弟合并，可能向上蔓延
B 树高度n 个关键字的 m 阶 B 树，高度 h 的范围大约是 logm(n+1) ≤ h ≤ log⌈m/2⌉((n+1)/2) + 1。把上下限的推导当成公式记，考试常给 n 和 m 让你估算高度。

4. B+ 树 vs B 树

B 树B+ 树
关键字存放每个结点都存数据只有叶子存数据，内部结点只做索引
关键字个数n 棵子树有 n−1 个关键字n 棵子树有 n 个关键字
叶子间无连接用指针串成有序链表
查找可能中途命中必须走到叶子（稳定）
适用文件索引数据库索引（范围查询快）

5. 散列表 计算题

哈希函数（最常用「除留余数法」） H(key) = key mod p p 一般取不大于表长的最大质数 装填因子 α = 表中记录数 n ÷ 表长 m α 越大冲突越多（ASL 只与 α 有关，与 n、m 绝对值无关）
冲突处理（两种大类） ① 开放地址法 线性探测：H+1, H+2, H+3 …（会产生「堆积」） 二次探测：H+1², H−1², H+2², H−2² … 再散列法：用第二个哈希函数 伪随机序列法 ② 拉链法（链地址法） 每个地址挂一个链表，冲突元素直接链上去 优点：不产生堆积、删除方便 适合表长不确定的情况
ASL 怎么算分别统计查找成功和查找失败的平均比较次数。查找失败时，探测到空位置才算一次失败查找 —— 所以分母是「哈希函数值域的大小」，不是 n。这是最容易算错的地方，下面的操作台会直接给出结果供你核对。

排序

核心 · 7-9 分
本章定位考点最「标准化」的一章：给定序列，写出某算法第 k 趟的结果，以及复杂度与稳定性的对比。这些题只要记住了过程就一定能做对，属于必拿分。下面做了可切换算法的排序演示台，建议先用笔算一遍再点动画核对。
考点清单

1. 五大类排序与过程

插入类 直接插入：把第 i 个元素插入前面已排好的序列 折半插入：用折半查找找插入位置（移动次数不变） 希尔排序：按增量分组插入排序，增量逐步减到 1 交换类 冒泡排序：相邻两两比较，每趟把最大/最小「冒」到末尾 快速排序：选枢轴，一趟划分成「小 | 枢轴 | 大」，再递归 选择类 简单选择：每趟选最小的放到前面 堆排序：建大根堆，反复取堆顶与末尾交换再调整 归并类 二路归并：相邻两两合并成有序段，段长翻倍 基数类 基数排序：按位从低位到高位分配 + 收集

3. 几个高频细节

  • 快排最坏情况：序列基本有序时退化为 O(n²)（每次划分只分出一个元素）
  • 快排空间：递归栈深度，平均 O(log n)，最坏 O(n)
  • 堆排序：建堆 O(n)，每次调整 O(log n)，共 n−1 次 → O(n log n)
  • 冒泡最好 O(n)：加了「本趟无交换就结束」的标志
  • 每趟确定一个元素最终位置的算法：冒泡、快速、简单选择、堆排序
  • 归并排序每趟只是让有序段变长，不能确定某个元素在最终位置
秒杀技巧题目给你一个序列和「第 2 趟排序后的结果」，问用的什么算法 —— 就看这趟确定了几个元素的最终位置。确定 1 个且已排好的在端部 → 冒泡/选择；在中间 → 快排；一个都没确定、只是段变长 → 归并。

4. 外部排序

  • 用于数据量太大、内存装不下的场景（数据存在磁盘上）
  • 时间主要花在磁盘读写（I/O）上，而不是比较
  • 两阶段：内部排序生成初始归并段 → 多趟归并
  • 多路平衡归并：k 路归并减少归并趟数。归并趟数 = ⌈logkm⌉（m 为初始归并段数）
  • 败者树：k 路归并时找最小元素从 O(k) 降到 O(log k)
  • 置换-选择排序：生成更长的初始归并段，减少段数
  • 最佳归并树：用哈夫曼树思想组织归并顺序，使 I/O 最少
核心结论增加归并路数 k 可以减少归并趟数，从而减少磁盘 I/O 次数；但 k 太大时内部比较开销上升，所以用败者树来平衡。
