# 408 四门课 · 交互式原理全景

把计算机学科专业基础综合（408）的四门课做成**五个可离线打开的单文件网页**：
每个考点配考点卡片、原理剖析，以及**能亲手操作、能改参数、能逐帧播放**的动画。

> 在线地址：**https://5ky0neW.github.io/cs408/**
>
> 也可以直接把仓库下载下来，双击任意 `.html` 离线打开。

## 每份页面有什么

- **SECTION 00 · 四门课全景定位** —— 本科目在 408 里的位置、与另外三门的**跨科目接口**（例如计组的虚拟存储 ↔ OS 的内存管理、数据结构的图算法 ↔ OSPF 路由）
- **各章分值权重与复习优先级** —— 按历年真题大致分值**降序**排列，分核心 / 主力 / 补充三档
- **考点卡片** —— 对比类知识用表格，公式用等宽文本块，易错点单独标注
- **原理动画** —— 分三类：计算器（改参数实时算）、分步演示（逐帧看过程）、可视化（波形、时空图、曲线）
- **自测速答** —— 每章结尾 1–3 道，答案直接给出并说明思路

## 技术说明

**约束**：单文件、零外部依赖、断网可用。

- 不使用任何框架、CDN、外部字体或 JS 库 —— 每个 `.html` 双击即可打开
- 公式一律用**纯文本 + Unicode 符号**（`× ÷ ⊕ ≥ ≈ ² ³`），不使用 LaTeX / MathJax
  —— 这样在笔记软件的 Markdown 预览里也能正常显示
- 动画用原生 SVG + 原生 JS 实现：`animateMotion` 做数据流动，`setTimeout` 串联分步演示，
  动态生成 SVG 做树 / 图 / 环形结构
- 全局速度控制通过包装 `setTimeout` / `setInterval` 实现，只放大 300–2000ms 区间

**离线合集版**：把五个页面各自完整嵌入一个 `<iframe srcdoc>`，用 `postMessage` 桥接页面间跳转。
不做「真合并」是因为各页有同名的 `id`、重复的全局变量与不同的主题色变量，
iframe 让每页在自己的文档里运行，天然隔离。

## 本地打开

克隆后直接双击任意 `.html`，或用任意静态服务器：

```bash
git clone https://github.com/5ky0neW/cs408.git
cd cs408
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。

## 更新方式

站点是纯静态文件，改完直接用 git 推送即可，GitHub Pages 会自动重新部署（约 1 分钟）：

```bash
git add -A
git commit -m "更新说明"
git push
```

若改动了任一科目页面，记得同步重建 `downloads/` 里的离线合集，否则那份还是旧内容。
